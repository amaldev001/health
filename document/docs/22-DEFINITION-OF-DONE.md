# Definition of Done

A feature is DONE only when:

- [ ] Requirement is clearly identified.
- [ ] Relevant design is documented.
- [ ] Backend implementation is complete.
- [ ] Frontend implementation is complete where applicable.
- [ ] Validation exists.
- [ ] Authorization is tested.
- [ ] Error states are handled.
- [ ] Loading/empty states are handled in UI where applicable.
- [ ] Tests are added/updated.
- [ ] Tests pass.
- [ ] No known critical security issue remains.
- [ ] API documentation matches implementation.
- [ ] Database documentation matches implementation.
- [ ] No secrets are committed.
- [ ] Code is reviewed.
- [ ] Change is reflected in the traceability matrix.
