# UI Screenshots & User Flow Walkthroughs

This directory holds visual assets and screenshots demonstrating the application's user interface, responsive layouts, and user workflows.

## Key Screens & Flows

1. **Public Landing Page & Doctor Search**: Demonstrates specialization filtering, doctor discovery, clinic configuration header, and responsive design.
2. **Patient Dashboard**: Displays scheduled/confirmed appointments, past medical history, and quick booking trigger.
3. **Booking Modal**: Shows dynamic 30-minute time slot selection calculated in the clinic's configured timezone.
4. **Doctor Dashboard**: Manages incoming appointment requests, status state transitions (`confirm`, `complete`, `cancel`), medical record entry modal, and weekly availability schedule editor.
5. **Admin Dashboard**: System metrics (appointments, active doctors, patients), user management (status toggles), doctor account onboarding modal, and specialization management.
