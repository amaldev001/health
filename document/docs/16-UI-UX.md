# UI/UX Specification

## Principles
- Clear healthcare-oriented interface.
- Responsive design.
- Consistent navigation.
- Accessible labels and form controls.
- Visible status feedback.
- No misleading medical claims.
- Avoid unnecessary complexity.

## Shared Components
- Navbar/sidebar
- Button
- Input
- Select
- Modal
- Table
- Card
- Badge/status indicator
- Alert
- Toast
- Loading skeleton/spinner
- Empty state
- Pagination where needed

## Appointment UI
Show:
- Doctor
- Specialization
- Date
- Time
- Status
- Relevant actions

Do not expose private clinical information in general appointment lists unless the role is authorized.
